# 代码职责与维护边界

## 数据通路
USB相机 → Python纯视频输出至扩展桌面 → 板卡HDMI输入 → RGB565缓存/DDR → FPGA逆仿射与镜头坐标映射 → 瓦片加载与最近邻/双线性重采样 → 输出缓存 → HDMI输出。自动预处理沿用V04的统计与RGB共用偏移实现；具体位置由顶层接线确定，未改接线顺序。

软件 camera_hdmi 管理摄像头和UI；rational_controls组合系数；affine_protocol/affine_serial/view_control/gamma_control承担协议编码、发送和确认；frame_export保存板上输出。全帧导出冻结的是板上输出，主机冻结输入是另一状态，两者不能混为一谈。

硬件 newddr3_top/HDMI_IN_DDR3_HDMI_OUT_top 负责系统集成；affine_frame_manager负责帧所有权；affine_frame_processor调度任务；affine_warp_coordinates选择模式、投影和镜头映射；affine_tile_*完成瓦片组织和采样；affine_pango_*适配DDR；adaptive_gamma执行原V04预处理；uart_frame_export提供串口整帧导出。

## 数值约定

仿射线性项Q16、平移项Q12；新参数rational镜头使用Q8主点、Q15径向表及对应切向常数。表索引、插值、舍入、有符号移位和valid掩码延迟均保持原版，不用旧Brown表替换新rational表。
双线性用于有效源像素间重采样，不凭空生成未拍摄内容；指定裁剪是等比例取景，没有加入非均匀拉伸。
平滑仿射目标为主机每秒提交30组系数；中间配置可被板端邮箱覆盖，因此不是显示端新鲜帧率承诺。

## 可核验结果

VALIDATION.json记录原目录完整性、代码语义对照和工具检查。COPY_MANIFEST.json记录从原目录复制的文件身份；其中源码SHA是注释前值，最终文件SHA见DELIVERY_SHA256.json。SELECTION.json列出移除类别与未被启动链引用的独立旧工具。
ANNOTATED_SYNTHESIS_REPORT.snr为本轮综合报告；ORIGINAL_TIMING_REPORT.rtr为原V04历史完整时序报告，两者不是同一次构建，不混写成新布局布线结果。
下载脚本唯一执行行为调整为日志写到logs并在需要时建目录；CMD只改变辅助脚本/工程路径并禁用字节码缓存。像素处理、相机默认配置和控制算法未调整。
